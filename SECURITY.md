# Security Policy

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Email **jacob@autopwn.sh** with:

- a description of the issue and its impact,
- steps to reproduce (or a proof of concept),
- any relevant logs or screenshots.

We aim to acknowledge within **3 business days** and will coordinate a fix and a
disclosure timeline with you. Please give us reasonable time to remediate before any
public disclosure.

## Scope

This repository and the deployed site at `humanriskmatrix.org`. The full security
model and controls are documented in [`docs/security.md`](docs/security.md).

## Supported versions

The project is pre-launch and ships from `main`; fixes land on `main`.
